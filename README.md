# Robotic_Perception_and_Autonomous_Navigation_ROS2_Dissertation-
# Dataset

The project uses a reproducible generated experimental dataset rather than an external downloaded dataset.

- `trial_results.csv` is the trial-level dataset generated by `scripts/run_ros2_navigation_evaluation.py`.
- `ros2_experiment_summary.json` records the fixed seed, grid size, conditions, planner names, trial counts and ROS message probe counts.

The fixed seed is `20260912`; this is the value used in the dissertation.
